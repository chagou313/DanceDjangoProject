# 知识图谱数据目录

## 📁 目录说明

此目录用于存放AI生成的舞蹈知识图谱JSON数据文件。

## 📋 文件命名规范

建议使用以下命名格式：
```
舞蹈项目名称.json
```

例如：
- `京西太平鼓.json`
- `永新盾牌舞.json`
- `安塞腰鼓.json`

## 🚀 使用流程

### 1. 生成数据
使用 `ai_prompt_template.md` 中的提示词，让AI生成JSON数据

### 2. 保存文件
将生成的JSON数据保存到此目录，文件名为舞蹈项目名称

### 3. 验证数据
检查JSON格式是否正确（可使用在线JSON验证工具）

### 4. 导入数据库

**导入单个文件：**
```bash
python manage.py import_knowledge_data --file=knowledge/data/京西太平鼓.json
```

**批量导入所有文件：**
```bash
python manage.py import_knowledge_data --dir=knowledge/data/
```

## 📝 数据模板参考

参考 `data_template.json` 文件的格式和结构

## ⚠️ 注意事项

1. **编码格式**：确保JSON文件使用UTF-8编码
2. **字段完整**：检查所有必填字段是否都存在
3. **数据准确**：验证难度等级、时长等数值是否合理
4. **避免重复**：相同项目多次导入会更新现有数据

## 🔧 常见问题

**Q: 导入时出现编码错误？**
A: 确保JSON文件保存为UTF-8编码（不含BOM）

**Q: 如何更新已有数据？**
A: 脚本使用get_or_create，相同名称的招式会保留，不会重复创建

**Q: 导入失败怎么办？**
A: 检查JSON格式是否正确，字段名是否与模板一致
