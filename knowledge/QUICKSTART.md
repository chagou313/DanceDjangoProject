## ⚡ 5分钟快速开始

### 第1步：选择要生成的舞蹈项目

例如：京西太平鼓

### 第2步：复制提示词模板

打开 `ai_prompt_template.md`，复制"模板1：完整项目生成"

### 第3步：填充项目信息

```
你是一位非遗传统舞蹈专家，请为【京西太平鼓】生成完整的知识图谱数据。

【项目信息】
- 项目名称：京西太平鼓
- 舞蹈类别：民间舞蹈
- 起源地：北京市门头沟区
- 历史渊源：起源于明代，已有600多年历史
- 舞蹈特点：以鼓为道具，动作刚劲有力，节奏明快
- 难度等级：3

[... 其余提示词保持不变 ...]
```

### 第4步：发送给AI

将填充好的提示词发送给AI助手

### 第5步：保存JSON文件

将AI返回的JSON数据保存到：
```
knowledge/data/京西太平鼓.json
```

### 第6步：导入数据库

```bash
python manage.py import_knowledge_data --file=knowledge/data/京西太平鼓.json
```

### 第7步：验证结果

访问知识图谱页面查看效果：
```
http://127.0.0.1:8000/knowledge/
```

选择"京西太平鼓"，查看生成的知识图谱！

## 🔄 批量生成流程

### 方案A：逐个生成（推荐新手）

```
重复以下步骤356次：
1. 选择一个舞蹈项目
2. 使用提示词生成数据
3. 保存JSON文件
4. 导入数据库
```

**优点**：可控性强，可随时调整  
**缺点**：耗时较长

---

### 方案B：分批次生成（推荐）

```
第1天：生成10个项目（测试流程）
第2-3天：生成50个主要民间舞蹈
第4-7天：生成100个少数民族舞蹈
第8-12天：生成剩余项目
```

**优点**：效率高，可并行处理  
**缺点**：需要协调多个AI会话

---

### 方案C：自动化生成（高级）

编写脚本自动调用AI API：

```python
import requests
import json

def generate_dance_data(project_info):
    """调用AI API生成数据"""
    prompt = build_prompt(project_info)
    
    response = requests.post(
        'https://api.ai-service.com/v1/chat',
        json={
            'model': 'gpt-4',
            'messages': [{'role': 'user', 'content': prompt}],
            'temperature': 0.7
        }
    )
    
    return response.json()['choices'][0]['message']['content']

# 批量处理
projects = load_projects_from_database()
for project in projects:
    data = generate_dance_data(project)
    save_to_json(data, f"knowledge/data/{project['name']}.json")
```

**优点**：全自动，速度最快  
**缺点**：需要API密钥和编程能力

## 🔧 故障排除

### 问题1：AI生成的JSON格式错误

**解决**：
- 在提示词末尾强调"必须输出有效的JSON格式"
- 使用JSON验证工具检查
- 手动修复小错误

### 问题2：数据量不足

**解决**：
- 在提示词中明确要求"每个模块至少12个招式"
- 追加提示："请继续生成更多招式，直到达到15个"

### 问题3：内容不够专业

**解决**：
- 提供更详细的背景资料
- 追加要求："请参考《中国民族民间舞蹈集成》等专业文献"
- 提供示范视频链接让AI观察

### 问题4：导入失败

**解决**：
- 检查错误信息
- 验证JSON字段名是否与模型一致
- 确保编码为UTF-8
- 查看详细错误日志
