### 模板1：完整项目生成（推荐）

```

- 招式名称要体现传统文化特色
```

### 模板2：单个模块生成（分步进行）

```
你是一位非遗传统舞蹈专家，请为【舞蹈项目名称】的【模块名称】生成详细数据。

【模块信息】
- 项目名称：[填写]
- 模块名称：[基本步伐模块/手势身段模块/队形变化模块/节奏韵律模块]
- 模块描述：[50-100字描述]

【生成要求】
请为该模块生成10-15个具体招式，按难度从低到高排列。

每个招式包含：
1. 招式名称（体现文化特色）
2. 详细描述（80-150字）
3. 难度等级（1-10，模块内递进）
4. 学习时长（180-600秒）
5. 完整的动作属性（发力部位、常见错误、标准要领、注意事项）
6. 3-5个学习资源
7. 4-6个知识点标签

【输出格式】
{
  "name": "模块名称",
  "description": "模块描述",
  "order_index": 1,
  "moves": [
    // 招式列表
  ]
}

请确保招式之间逻辑递进，从基础到进阶。
```

### 模板3：招式详情生成（精细化）

```
请为【舞蹈项目】的【招式名称】生成详细的技术分析。

【招式背景】
- 所属模块：[模块名称]
- 难度等级：[1-10]
- 动作特点：[简要描述]

【需要生成的内容】

1. 详细描述（80-150字）
   包括：动作流程、技术要求、艺术表现

2. 动作属性：
   - 发力部位：哪些肌肉群参与，如何发力
   - 常见错误：初学者容易犯的3-5个错误
   - 标准要领：正确的技术要点
   - 注意事项：安全提示和练习建议

3. 学习资源（3-5个）：
   - 教学视频
   - 传承人示范
   - 图文教程或理论文章

4. 知识点标签（4-6个）：
   - 技法要点类
   - 文化内涵类
   - 表演技巧类
   - 训练方法类
   - 历史渊源类

【输出格式】
{
  "name": "招式名称",
  "description": "...",
  "difficulty": 5,
  "duration": 300,
  "order_index": 1,
  "attributes": {...},
  "resources": [...],
  "knowledge_points": [...]
}

请确保内容专业、准确、实用。
```

## 📋 使用步骤

### 方法A：一次性生成整个项目

1. 复制**模板1**
2. 填充项目信息
3. 发送给AI
4. 等待生成完整JSON
5. 保存为 `data/项目名称.json`
6. 使用导入脚本导入数据库

**优点**：快速、数据一致性好  
**缺点**：AI可能超出token限制，需要分段

---

### 方法B：分模块生成（推荐）

1. 为每个模块使用**模板2**
2. 依次生成4个模块
3. 合并到一个JSON文件
4. 导入数据库

**优点**：数据质量高、可控性强  
**缺点**：需要多次操作

---

### 方法C：混合方式

1. 用模板1生成框架（只有招式名称）
2. 用模板3逐个细化重要招式
3. 合并数据

**优点**：兼顾效率和质量  
**缺点**：操作较复杂

## 💡 优化技巧

### 提高数据质量的提示词追加

在基础提示词后添加：

```
【额外要求】
1. 招式名称要避免现代化词汇，使用传统术语
2. 动作描述要结合解剖学和运动学原理
3. 常见错误要基于实际教学经验
4. 知识点要体现该舞蹈的独特文化价值
5. 参考《中国民族民间舞蹈集成》等专业文献
6. 考虑不同年龄段学习者的接受能力
```

### 针对特定舞蹈类型的调整

**民间舞蹈**：
```
强调：生活气息、地域特色、群众参与性
招式命名：可使用方言词汇、地方特色用语
```

**宫廷舞蹈**：
```
强调：礼仪规范、优雅气质、程式化动作
招式命名：使用古典文学词汇、诗词意象
```

**宗教祭祀舞蹈**：
```
强调：仪式感、象征意义、神秘色彩
招式命名：结合宗教术语、法器名称
```

**少数民族舞蹈**：
```
强调：民族特色、服饰道具、节庆习俗
招式命名：使用民族语言音译、图腾象征
```

## ⚡ 快速命令

将以下内容保存为 `generate_prompt.txt`，每次只需修改项目名称：

```
你是一位非遗传统舞蹈专家，请为【{{PROJECT_NAME}}】生成完整的知识图谱数据。

【项目信息】
- 项目名称：{{PROJECT_NAME}}
- 舞蹈类别：{{CATEGORY}}
- 起源地：{{REGION}}
- 舞蹈特点：{{FEATURES}}
- 难度等级：{{DIFFICULTY}}

请生成4个基础动作模块，每个模块包含10-15个具体招式。

[... 其余模板内容 ...]
```

使用时：
```bash
# 替换占位符
sed 's/{{PROJECT_NAME}}/京西太平鼓/g' generate_prompt.txt > prompt_final.txt
sed -i 's/{{CATEGORY}}/民间舞蹈/g' prompt_final.txt
# ... 继续替换其他变量

# 复制prompt_final.txt的内容发送给AI
```
