========================================
数据导入指南
========================================

📁 文件存放位置
========================================

请将您的 Excel 文件放在以下任一位置：

【推荐】项目根目录的 data 文件夹：
data/traditional_dance_data.xlsx（项目根目录下）

或者使用绝对路径（任意位置）：
C:\Users\YourName\Desktop\traditional_dance_data.xlsx


========================================
📋 Excel 文件格式要求
========================================

Excel 文件应包含以下工作表（Sheet）：

1. 舞蹈项目（必填）
   列名：编号 | 项目名称 | 名称 | 类别 | 公布时间 | 类型 | 申报地区或单位 | 保护单位

2. 传承人（可选）
   列名：序号 | 姓名 | 性别 | 出生日期 | 民族 | 类别 | 项目编号 | 项目名称 | 申报地区或单位

3. 相关项目（可选）
   列名：编号 | 项目名称 | 类型 | 类别 | 申报地区或单位

4. 相关资讯（可选）
5. 学术研究（可选）

详细说明请参考：excel_template_guide.txt


========================================
🚀 导入方法
========================================

方法一：使用默认路径（推荐）
----------------------------------------
1. 将 Excel 文件放到 data 文件夹
2. 命名为：traditional_dance_data.xlsx
3. 在项目根目录运行：
   python manage.py import_excel_data


方法二：指定文件路径
----------------------------------------
python manage.py import_excel_data 文件路径.xlsx

示例：
python manage.py import_excel_data data/my_dance_data.xlsx
python manage.py import_excel_data ~/Desktop/data.xlsx


========================================
📦 依赖安装
========================================

如果提示需要安装 pandas 和 openpyxl：

pip install pandas openpyxl


========================================
✅ 验证导入结果
========================================

导入完成后，访问网站查看：

1. 舞蹈起源列表：http://localhost:8000/origin/
2. 项目详情：http://localhost:8000/origin/Ⅲ-1/


========================================
⚠️ 注意事项
========================================

1. 首次导入建议先用小数据集测试
2. 确保 Excel 文件没有被其他程序打开
3. 列名必须完全匹配（包括中文）
4. 项目编号应该唯一
5. 日期格式使用 YYYY-MM-DD 或文本格式


========================================
🔧 故障排除
========================================

问题 1：找不到文件
解决：检查文件路径是否正确，注意 Windows 路径使用双反斜杠或原始字符串

问题 2：中文乱码
解决：确保 Excel 文件保存为 UTF-8 编码的 .xlsx 格式

问题 3：关联失败
解决：确保传承人的项目编号在舞蹈项目中已存在

问题 4：导入速度慢
解决：大数据集可以分批导入，或注释掉部分可选工作表的导入
